## 인삿말

안녕하세요. 프로그래밍 전문 강사 박지훈입니다.

2018년부터 현재까지 초등학생부터 고등학생까지 다양한 연령층을 대상으로 프로그래밍 수업을 진행해 왔습니다. 학생들이 쉽고 재미있게 배울 수 있도록 수업 방식에 끊임없이 변화를 주고 있으며, 신기술과 언어 업데이트도 빠르게 반영해 수업에 적용하고 있습니다.

처음 프로그래밍을 접하는 학생에게는 블록 코딩이나 비주얼 스크립트로 시작하여 점진적으로 텍스트 기반 언어로 확장시켜, 자신만의 작품을 구현할 수 있도록 도와줍니다. 또한 알고리즘 수업, 입시 포트폴리오, 각종 대회 및 프로젝트 지도를 통해 실제 성과를 만들어낸 경험이 풍부합니다.

아래는 저의 강의 과목과 지도 성과를 요약한 내용입니다.

## 강의 과목

### ▶ 블록 코딩

#### 1. 엔트리

* 방과 후 수업 및 프로그래밍 봉사활동 자료로 활용
* 사용 교재: 송쌤의 엔트리 코딩학교

#### 2. 스크래치 / S4A

* 기본 문법 및 예제 중심 수업
* 지역 과학 축제 기출 문제 기반 수업
* S4A로 토이 프로젝트 제작 (LED, 센서 등 하드웨어 활용)
* COS 자격증 대비 수업 진행
* 사용 교재: 모두의 스크래치, COS 2급 대비서, 학원 자체 교재

#### 3. 앱인벤터

* 초중등 대상 모바일 앱 제작 수업
* 토이 프로젝트 및 학원 분기별 작품 제작에 활용
* 사용 교재: 학원 자체교재

### ▶ 언어 기반 프로그래밍

#### 1. C

* 문법 및 기초 프로그래밍 개념 중심 수업
* C++/C# 기초 과정으로 활용
* 사용 교재: 열혈 C 프로그래밍 외

#### 2. C++

* 입출력, 클래스, STL 활용 등 심화 문법 수업
* 최신 문법 안내(C++14, 17)
* 사용 교재: 열혈 C++ 프로그래밍

#### 3. Java / Kotlin

* 모바일 앱 제작 및 내신 대비 수업
* Java와 Kotlin 병행 수업
* 사용 교재: 자바의 정석, 이것이 안드로이드다 외

#### 4. Python

* 문법 및 라이브러리 활용 수업
* 정보올림피아드, 데이터 분석(CoLab 활용) 병행
* 사용 교재: 점프 투 파이썬, 이것이 코딩 테스트다, 자체 제작 프로젝트 수업 외

#### 5. C# / Unity

* Unity 게임 개발 및 포트폴리오용 프로젝트 제작
* 사용 교재: 이것이 C#이다, Unity 교과서, 자체 교재

#### 6. Lua / Roblox

* 초중등 특강 수업
* 본 수업은 obby 프로젝트 부터 이벤트, 객체, 네트워크와 데이터 베이스 수업까지 진행
* 사용 교재: 자체 제작 방학 특강 자료, 학원 수업 자료, 자체 제작 프로젝트 수업 자료

#### 7. C++ / Unreal Engine

* 고성능 PC 보유 학생 대상 고퀄리티 프로젝트 제작
* 블루프린트 방식 수업 포함
* 사용 교재: 언리얼 엔진 4 실전 게임 제작 외

#### 8. 웹 개발 (HTML/CSS, JS, Node.js)

* 포트폴리오 제작 중심 기초 웹 수업
* jQuery, Ajax, Node.js까지 확장 수업
* 사용 교재: 웹 프로그래밍 기초, Node.js 교과서


#### 9. rust

* 알고리즘의 특별함을 주기 위한 전략으로 선택한 언어, 다른 학생들 처럼 c/c++, java, python으로 언어적 평범함을 탈피하기 위해 선택
* 블록체인(solidity)에도 도움이 될 것으로 확인하여 수업을 진행
* 사용 교재: [온라인 문서](https://doc.rust-kr.org/), do-it 알고리즘 코딩 테스트

## 지도 성과

<br>

### 입시

#### ▶ 영재 교육원 합격 지도 (가천대, 아주대, 서울여대)

* 프로젝트 및 과제 기반 작품 지도 4명 / 총 4명 합격  (전원 합격)
* 학생 프로젝트 기획, 제작 및 설계 모두 관여하고 면접 대비 역시 모두 관여
* 가천대
  - 제목: 실생활에서 찾을 수 있는 센서와 원리 (제작, 기획, 설계)
    * 개요: 자동문, 로봇 청소기에서 동작하는 적외선 센서의 원리를 주파수별로 데이터 그래프를 활용한 보고서 형식의 프로젝트
    * 기술 스택: arduino, 적외선 센서
  - 제목: 안전한 씨앗 보관 (기획(보완), 제작, 설계)
     * 개요: 개체 멸종이라는 인류의 큰 위기앞에서 씨앗 은행(Seed Vault)을 통해 안전한 종 보존을 할 수 있는 시스템 구축 프로젝트
     * 기술 스택: arduino, app inventor, 온습도 센서, 블루투스 모듈
* 아주대
  - 프로그래밍 면접 대비로 수학과 연계할 수 있는 면접 준비를 진행
  - 학생이 작성한 문서를 바탕으로 예상 질문과 강조할 수 있는 포인트 면접 방식 지도 
* 서울여대
  - 정보보안과 관련된 내용으로 당시 TeamH4c 소속 인원과 얘기하여 영재원에서 다루는 주요 테마 선행 학습
  - 학생의 장점을 살리기 위한 전문적 지식보다는 관심과 영재원간의 연결로 서류 작성을 도와줌

#### ▶ 고등학교 입시 합격 지도

* 디미고, 단대소고, 경기과고, 선린고 등 특기자 전형 대비 (현재 단대소고와 선린고를 중심으로 지도)
* 입시 전략 수립 및 포트폴리오 제작 지도
* 단국대 부속 소프트웨어 고등학교
    - 프로젝트명: 스포츠 과학을 통한 학생 야구부 데이터 분석 시스템 (제작, 기획, 설계)
      * 개요: 심리적인 영향이 많은 학생 선수들을 대상으로 심리 안정 효과를 만드는 루틴 소개와 자신의 데이터를 바탕으로 운동에서의 전략 수립 프로젝트
      * 기술 스택: python, tkinter
   - 프로젝트명: 나만의 게임 평론 프로그램 (제작, 기획, 설계)
      * 개요: metacritic 사이트 정보를 안드로이드 앱으로 불러와서 원하는 정보를 쉽고 빠르게 확인할 수 있는 프로그램
      * 기술 스택: 웹 스크래핑, app inventor
   - 프로젝트명: 새로운 테이블 퍼즐 게임 (제작, 설계)
      * 개요: 오셀로에서 아이디어를 가져와 자신만의 규칙으로 제작한 퍼즐 게임
      * 기술 스택: unity
* 경기과학고등학교
    - 연구 주제: 데이터 크기별 정렬 알고리즘의 효율성 고찰
      * 개요: 향상된 버블 정렬, 퀵 정렬, 병합 정렬, 기수 정렬을 기반으로 시간 복잡도와 데이터와의 상관 관계가 실제 빅오 표기법을 이루는지에 대한 연구
      * 기술 스택: C++
* 선린 인터넷 고등학교  
    - 서류(2023): 해킹 관련 업적이 많은 학생이었으나, 학교 내신이나 활동이 약하여 외부 활동에 의한 학교 관리 미흡을 강조하고 대신 학교에 필요한 내용과 면접 대비를 통하여 인재상에 적합할 수 있도록 서류 수정을 했고 결과는 입학
    - 서류(2024): 코딩적 성과나 관심도가 떨어진 서류를 첨삭과 함께 새로 다듬어서 학교에 맞는 그리고 2024년 코딩 트랜드인 AI를 본인의 서류에 접목시켜서 합격

#### ▶ 대학교 입시 지도

* 한국 대학교의 경우 생기부 관리를 위해 학교 교과와 프로그래밍을 융합한 프로젝트 제작 및 연구 보고서 지도
* 외국 대학교의 경우 AP, IB와 관려된 내용을 수업
  * AP: AP-A의 경우 자바 중심으로 MCQ, FRQ 모두 수업
  * IB: IB-HL 수업으로 TOPIC 전부를 수업 - 인도 유학 ( 7 / 7)
    * 프로젝트명: sci grapher
    * 개요: 기존의 선형회귀분석 프로그램의 한계를 극복하여 데이터 테이블의 새로운 데이터를 탑재한 새로운 선형회귀분석 프로그램
    * 기술 스택: flutter(web), firebase auth, firebase core, cloud_firesotre, intl
