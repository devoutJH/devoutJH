## 인삿말

안녕하세요. 프로그래밍 전문 강사 박지훈입니다.

2018년부터 현재까지 초등학생부터 고등학생까지 다양한 연령층을 대상으로 프로그래밍 수업을 진행해 왔습니다. 학생들이 쉽고 재미있게 배울 수 있도록 수업 방식에 끊임없이 변화를 주고 있으며, 신기술과 언어 업데이트도 빠르게 반영해 수업에 적용하고 있습니다.

처음 프로그래밍을 접하는 학생에게는 블록 코딩이나 비주얼 스크립트로 시작하여 점진적으로 텍스트 기반 언어로 확장시켜, 자신만의 작품을 구현할 수 있도록 도와줍니다. 또한 알고리즘 수업, 입시 포트폴리오, 각종 대회 및 프로젝트 지도를 통해 실제 성과를 만들어낸 경험이 풍부합니다.

아래는 저의 강의 과목과 지도 성과를 요약한 내용입니다.

## 강의 과목

### ▶ 블록 코딩

#### 1. 엔트리

* 방과 후 수업 및 프로그래밍 봉사활동 자료로 활용
* 사용 교재: 송쌤의 엔트리 코딩학교

* 사용 교재: 모두의 스크래치, COS 2급 대비서, 학원 자체 교재

#### 3. 앱인벤터

* 초중등 대상 모바일 앱 제작 수업
* 토이 프로젝트 및 학원 분기별 작품 제작에 활용
* 사용 교재: 학원 자체교재

### ▶ 언어 기반 프로그래밍

#### 1. C

* 문법 및 기초 프로그래밍 개념 중심 수업
* C++/C# 기초 과정으로 활용
* 사용 교재: 열혈 C 프로그래밍 외

#### 2. C++

* 입출력, 클래스, STL 활용 등 심화 문법 수업
* 최신 문법 안내(C++14, 17)
* 사용 교재: 열혈 C++ 프로그래밍

#### 3. Java / Kotlin

* 모바일 앱 제작 및 내신 대비 수업
* Java와 Kotlin 병행 수업
* 사용 교재: 자바의 정석, 이것이 안드로이드다 외

#### 4. Python

* 문법 및 라이브러리 활용 수업
* 정보올림피아드, 데이터 분석(CoLab 활용) 병행
* 사용 교재: 점프 투 파이썬, 이것이 코딩 테스트다, 자체 제작 프로젝트 수업 외

#### 5. C# / Unity

* Unity 게임 개발 및 포트폴리오용 프로젝트 제작
* 사용 교재: 이것이 C#이다, Unity 교과서, 자체 교재

#### 6. Lua / Roblox

* 초중등 특강 수업
* 본 수업은 obby 프로젝트 부터 이벤트, 객체, 네트워크와 데이터 베이스 수업까지 진행
* 사용 교재: 자체 제작 방학 특강 자료, 학원 수업 자료, 자체 제작 프로젝트 수업 자료

#### 7. C++ / Unreal Engine

* 고성능 PC 보유 학생 대상 고퀄리티 프로젝트 제작
* 블루프린트 방식 수업 포함
* 사용 교재: 언리얼 엔진 4 실전 게임 제작 외

#### 8. 웹 개발 (HTML/CSS, JS, Node.js)

* 포트폴리오 제작 중심 기초 웹 수업
* jQuery, Ajax, Node.js까지 확장 수업
* 사용 교재: 웹 프로그래밍 기초, Node.js 교과서
